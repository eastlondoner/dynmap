About Dynmap

Dynmap® is a powerful plugin that provides dynamic, real-time web-based maps for your Minecraft server. Players can view their world through a web browser, see live player locations, and explore the terrain even when they're not in-game.

Building from Source

⚠️ Important Update: This repository includes a critical JAXB fix for AWS S3 storage backend compatibility with Java 17/21. If you use S3 storage, build from this source to avoid JAXBException errors.

To build Dynmap from source code, you'll need:

  • JDK 21 (for Minecraft 1.20.5+ support)
  • Gradle 8.7+

Run the following command to build all platforms:

./gradlew setup build

Built JARs will be placed in the target/ directory.

Latest Fix: JAXB dependencies for S3 storage have been updated and properly shaded to prevent classpath conflicts on modern Java versions.
